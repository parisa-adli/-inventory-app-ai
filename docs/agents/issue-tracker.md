# Issue Tracker

Issues for this repository are tracked in **GitHub Issues**.

## Creating issues

Use the `gh` CLI:

```bash
gh issue create --title "Title" --body "Description"
```

## Listing issues

```bash
gh issue list
```

## PRs as a request surface

**Disabled.** External pull requests are not automatically added to the triage queue. If you want PRs to flow through triage, set this flag to `true` and the `triage` skill will include open PRs in its scan.
